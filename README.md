# Go CI/CD Pipeline App

Учебный проект для демонстрации настройки CI/CD для приложения на **Go (Golang)** с использованием **GitHub Actions** и **Docker**.

Пайплайн включает:
- Загрузку зависимостей
- Линтинг (`golangci-lint`)
- Запуск тестов с проверкой покрытия кода
- Сборку минималистичного Docker-образа
